# FARIDOS SIGN — بروتوتيب

منصة تكتشف "بصمة الرائحة" (Scent DNA) للمستخدم عبر استبيان من 12 سؤالًا، ثم توصي بعطر
من كتالوج مُنتقى وتبني معادلة عطر مخصصة (هرم نوتات: عليا / وسطى / قاعدية) بناءً على
مكتبة المكونات المرفقة.

## التقنيات
Next.js 14 (App Router) · TypeScript · Tailwind CSS · shadcn/ui · Prisma + PostgreSQL · React Hook Form + Zod

## التشغيل محليًا

```bash
# 1. تثبيت الحزم
npm install

# 2. إعداد قاعدة البيانات
cp .env.local.example .env.local
# عدّل DATABASE_URL في .env.local لتشير إلى قاعدة PostgreSQL الخاصة بك

# 3. إنشاء الجداول وزرع البيانات
npm run db:push
npm run db:seed

# 4. تشغيل بيئة التطوير
npm run dev
```

افتح http://localhost:3000

## بنية المسارات

| المسار | الوصف |
|---|---|
| `/` | الصفحة الرئيسية (Hero) |
| `/survey` | الاستبيان التفاعلي (12 سؤالًا موزعة على 6 مجموعات) |
| `/results` | بصمة الرائحة + العطر المطابق + هرم النوتات + نموذج التقاط العميل |
| `/perfume/[id]` | تفاصيل عطر من الكتالوج |
| `/thank-you` | تأكيد إرسال بيانات العميل |

## كيف يعمل محرك التوصية (`lib/recommendation-engine.ts`)

1. **بناء بصمة الرائحة (Scent DNA):** يُعطى وزن أكبر للعائلة الرئيسية المختارة، ثم
   الثانوية، ثم تُضاف نقاط من النوتات المفضلة الثلاث وعائلاتها المنسجمة (`harmony`).
2. **مطابقة الكتالوج:** كل عطر في `lib/perfume-catalog.ts` يُقيَّم مقابل بصمة المستخدم
   (45 نقطة) + الجنس (15) + التوقيت (10) + الموسم (10) + الاستخدام (10) + الثبات (5) +
   الحضور (5)، فيُختار الأعلى نتيجة.
3. **معادلة مخصصة:** يُبنى هرم نوتات (عليا/وسطى/قاعدية) من `lib/ingredients-data.ts`
   بالاعتماد على النوتات المفضلة والعائلات الأعلى في البصمة، مع ضبط التركيز حسب
   ميزانية المستخدم واحترام سقف `maxConc` لكل مكوّن.

## بيانات V1

- 14 سؤال استبيان (`lib/survey-data.ts`) — القيمة الفعلية 12 سؤالًا كما هي في نص الطلب.
- 20 مكوّن عطري (`lib/ingredients-data.ts`) موزعة على نوتات عليا/وسطى/قاعدية.
- 6 عطور كتالوج (`lib/perfume-catalog.ts`) كأمثلة أولية — يمكن توسيعها من خلال Prisma
  Studio (`npm run db:studio`) أو تعديل الملف مباشرة وإعادة الزرع.

## نموذج قاعدة البيانات (`prisma/schema.prisma`)

- `Ingredient` — مكتبة المكونات العطرية
- `Perfume` — كتالوج العطور الجاهزة
- `SurveyResult` — كل نتيجة استبيان (بصمة الرائحة، درجة التوافق، المعادلة المخصصة)
- `Lead` — بيانات العملاء المهتمين (مرتبطة بنتيجة استبيان واحدة)

## ملاحظات حول هذا البروتوتيب

- حفظ النتيجة في قاعدة البيانات يحدث في الخلفية (`fetch` بدون انتظار) حتى لا يتوقف
  تدفق المستخدم إذا كانت قاعدة البيانات غير متصلة بعد — تجربة الاستبيان والنتائج
  تعمل بالكامل محليًا (`sessionStorage`) حتى بدون PostgreSQL.
- الأيقونات: `lucide-react`. الحركات: CSS transitions بسيطة (`animate-fade-in`).
- الخطوط: Cairo للعربية، Inter للإنجليزية — محمّلة من Google Fonts في `app/globals.css`.
- زر "مشاركة النتيجة" يفتح حوار مشاركة فيسبوك القياسي (`sharer.php`) ويوفر بديل نسخ رابط.
